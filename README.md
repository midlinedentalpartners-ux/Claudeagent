# Claudeagent

COO agent workspace for Midline Dental Partners. Start with [`CLAUDE.md`](./CLAUDE.md), which Claude reads at the start of every session.

- `agents/`: the agent list
- `clients/<slug>/`: per-client notes, KPIs, meetings, data (read-only inputs) and deliverables
- `midline/`: internal product work
- `scripts/`: Graph API, openpyxl and python-docx helpers
- `templates/`: SOP, agenda, recap, digest and model templates
